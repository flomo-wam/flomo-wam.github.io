# flomo-wam.github.io

The collaborator release draft is at [release-thread.html](https://flomo-wam.github.io/release-thread.html). Its eight posts use results from the September 16, 2026 ICRA 2027 manuscript, linked on the [current project page](https://flomo-icra.github.io/).

The thread includes updated in-distribution and RoboTwin figures and reports the different OOD trial counts for the full-data model (18/30) and no-human-video ablation (1/15). Other pages and the earlier release video remain unchanged.

The thread uses one video in posts 1, 2, and 5; one image in posts 3, 4, 6, and 7; and two images in post 8. Each caption links to the actual attachment. This avoids depending on mixed-media support and fits the [X API attachment rules](https://docs.x.com/x-api/posts/create-post). Copy buttons include only the post text.

The scene-flow attachment is a 1280×720 H.264 export of the existing board-lifting example, padded without cropping. The human-video ablation is exported as a PNG so it can be attached directly rather than recreated from the webpage.
